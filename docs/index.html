《謎魅狩獵》戰術應對總綱

TACTICAL SURVIVAL BRIEFING // MIMESIS CONTAINMENT PROTOCOL
戰術總則
⚡ 原則一：辨識與破綻洞察
  • 動態行為偽裝：0.3.0 更新後怪物具備跳舞、上車放廢料、假藥水等高階社交欺詐。
  • 聲響感官雙刃劍：部分怪物怕巨響（野蠻兔），部分怪物對噪音極度暴怒（指揮家）。
  • 視線凝視制約：高危目標具備「看著即止步」的凝視機制（哨兵）。
🛡️ 原則二：避戰為最高準則
  • 彈藥零收益原則：在《謎魅狩獵》中，擊殺怪物通常不掉落戰利品。
  • 體力即生命：面對自爆魔等威脅，預留耐力狂奔是唯一解，嚴禁隨意耗盡體力。
  • 地形卡位機制：面對高血量重裝坦克（Heavy D），利用複雜轉角卡怪後撤離。
🎯 原則三：精準反擊與破招
  • 霰彈槍經濟學：霰彈槍是救急保險，優先保留給哨兵、迫近的炸彈魔與假人。
  • 硬直破招窗口：利用紳士貓頭鷹旋轉後的停頓、雙槍羊瞄準定格進行反殺。
  • 團隊拆解連攜：一人吸引/凝視，一人繞背遠程處決。

01. Mimesis (模仿者 / 假人)

THE MIMIC // SOCIAL DECEPTION & WEAPON HIJACKER
危險度 ★★★★☆
⚡ 攻擊方式
  • 致命掐頸：近距離施加 50% ~ 80% 巨量感染條。
  • 物品欄武裝鏡像（複製機制）：極度危險！它會直接複製玩家的四格物品欄；只要背包內有武器，無論手持為何，它都能掏出同款武器打你（非搶走你手中的武器）！
  • 死者附身：隊友死亡後，假人能短暫附身其屍體繼續語音說話。
🛡️ 避戰方式
  • 識破破綻：0.3.0 改版後會跑跳、唱歌跳舞、上車放廢料、丟假藥水。語音對答不自然者立即警惕。
  • 唯快不破：一旦確認為假人，「跑，直接跑！」，絕不逗留。
  • 物資防護：未持有重火力時，切勿在背包留存高殺傷武器貼近它。
🎯 反擊方式
  • 霰彈槍 (最高性價比)：近距離 1 發直接秒殺。
  • 搖滾球棒：連續 2 下重擊 擊斃。
  • 普通球棒：需命中 3 下（防範被其掏出複製武器反打）。
  • 團隊 SOP：一人保持距離正面牽制，隊友側翼 1 槍霰彈處決。
實測備註： 看到隊友熱情遞上「治療藥水」，或在載具上詭異跳舞時，切記暗號確認，切莫輕易靠近！

02. Bombesis (炸彈魔)

BOMBER MIMIC // TICKING TIME-BOMB
危險度 ★★★★☆
⚡ 攻擊方式
  • 全域即死自爆：接近玩家後啟動引信倒數，倒數結束產生毀滅性範圍爆炸。
  • 威脅判定：近距離無差別秒殺，波及周邊所有隊友與掩體。
🛡️ 避戰方式
  • 保留體力是唯一生存法規：平時搜刮切勿隨意耗盡耐力。
  • 聞聲即狂奔：靠近時會發出急促的「逼逼逼——」聲，一旦響起立刻調頭用盡體力狂奔！
  • 必死特性：只要你拉開安全距離，它倒數完畢後一定會自己炸死，無傷通關。
🎯 反擊方式
  • 嚴禁近戰肉搏：任何近戰攻擊必定遭自爆波及同歸於盡。
  • 遠程提前引爆：窄道無法避開時，使用霰彈槍 1 發遠程擊殺。
實測備註： 其實這隻最好處理！只要記住：聽到逼逼聲立刻跑，讓他自己炸死即可。

03. Brute Bunny (野蠻兔)

BRUTE BUNNY // NOISE PHOBIA STRIKER
危險度 ★★★☆☆
⚡ 攻擊方式
  • 高速衝刺重擊：手持重型鈍器直線快速追擊。
  • 兩下致命：傷害極高，貼身兩下即可擊殺玩家。
🛡️ 避戰方式
  • 特異聲學克制：大聲喧嘩！
  • 麥克風嚇退法：發出大量聲音或麥克風持續大聲講話、尖叫，野蠻兔會受到驚嚇直接被嚇退逃跑。
  • 在頻繁語音溝通的團隊面前，野蠻兔幾乎形同虛設。
🎯 反擊方式
  • 霰彈槍壓制：在退縮硬直中，3 發霰彈槍以內 可收走。
  • 語音控制鏈：一人開麥大叫吸引其猶豫，另一人持槍穩定輸出。
實測備註： 如果你的團隊很吵很聒噪，野蠻兔就是一隻被動靶子；但若處於靜音摸黑潛行，務必小心其突襲！

04. Mama Monkey (猴子媽媽 / 抓猴哥)

MAMA MONKEY // FORMATION DISRUPTOR
危險度 ★★☆☆☆
⚡ 攻擊方式
  • 強行擒拿漫遊：抓住玩家在設施內四處遊蕩，或強行將玩家拖往撤離出口。
  • 抓人無傷害：純被抓狀態自身受到傷害為 0。
  • 武器化假人：若場上有假人被其抓到，它會把假人當武器重重敲擊玩家！
🛡️ 避戰方式
  • 隊友普通敲 1 下即刻解救：同伴被抓時，任何隊友上前隨便敲它一下，它就會立刻鬆手放下玩家。
  • 出口搭便車（特殊情境）：如果正好想撤退，被它抓往出口有時反而是省耐力的順風車。
🎯 反擊方式
  • 霰彈槍：1 發直接擊斃。
  • 球棒：連續揮擊 3 下 即可收走。
  • 處置優先級：防止其抓取假人造成高傷威脅，實戰中建議「看到就直接扁」。
實測備註： 雖然抓人無傷，但極容易把隊員分散拖入其他危險區域，務必保持團隊走位互保！

05. Quakka Glider (矮袋鼯鼠 / 沉默鼯鼠)

QUAKKA GLIDER // SILENCE & BLIND AMBUSH
危險度 ★★☆☆☆ (連攜 ★★★★★)
⚡ 攻擊方式
  • 無聲滑翔撲臉：從天花板無預警飛撲至玩家面部撒嬌。
  • 直接傷害為 0：無物理扣血，但造成嚴重的感官剝奪。
  • 黑屏 + 完全消音：遮擋受害者視野，且隊友完全聽不到受害者語音說話！
🛡️ 避戰方式
  • 防範「炸彈魔連鎖」：鼯鼠撲臉讓你無法呼救，一旦此時炸彈魔逼近，你將化身無聲自爆引線！
  • 冷靜背靠牆壁：被撲臉後切忌盲跑，後退貼牆防止撞入陷阱。
🎯 反擊方式
  • 球棒精準 1 擊：體型極脆，球棒 1 下直接致死（需抓準滑翔停滯時機）。
  • 隊友互助：隊友看到某人突然啞巴且頭上有怪，立刻揮棒替其拍死。
實測備註： 這隻鼯鼠的存在就是為了替【Bombesis 炸彈魔】鋪路的惡意設計，務必優先擊落！

06. Standing Owl (站立的貓頭鷹 / 紳士貓頭鷹)

STANDING OWL // TERRITORIAL BLADE HURRICANE
危險度 ★★★☆☆
⚡ 攻擊方式
  • 羽翼旋轉風暴：以自身為圓心高速旋轉羽翼利刃。
  • 一巴掌扇死：貼身範圍極高秒殺傷害，被扇到直接暴斃。
🛡️ 避戰方式
  • 「真正的紳士」：你不主動接觸它，它**完全不動、不追擊**！
  • 繞開走即可：保持 3 米以上安全間距直接跑過去，無需潛行或蹲伏。
🎯 反擊方式
  • 旋轉空窗硬直：靠近觸發其旋轉一次後，在下一次旋轉前有大量硬直空窗期。
  • 球棒反殺：在硬直期間上前用球棒揮擊 2 下 即死。
  • 霰彈槍：貼臉 1 發 秒殺。
實測備註： 堵在窄門時才需要動手，否則請尊重這位紳士，直接擦肩而過即可。

07. Maegoostro (莓戈斯特羅 / 沉默的指揮家)

MAEGOOSTRO // SILENCE ENFORCER
危險度 ★★☆☆☆
⚡ 攻擊方式
  • 指揮棒爆頭：感知到噪音後快步走近，持指揮棒猛敲頭部造成傷害。
  • 噪音狂暴：極度排斥說話聲與手持道具的金屬碰撞響聲。
🛡️ 避戰方式
  • 「Be quiet ! 請閉嘴，手上的東西也請安靜！」
  • 絕對靜音通過：麥克風閉嘴、蹲下慢步前進，只要無聲，它視若無睹。
🎯 反擊方式
  • 全遊戲最脆實體之一：防禦低下，血量極薄。
  • 霰彈槍：直接正面 2 發散彈 收走。
  • 聒噪玩家解法：如果隊伍習慣頻繁語音報位，與其憋著不如直接兩槍轟殺。
實測備註： 擊殺無獎勵，若全隊能配合閉嘴 5 秒，它是最容易無傷規避的怪物。

08. Heavy D (海維·D / DJ坦克)

HEAVY D // RESOURCE SINK TANK
危險度 ★★★★☆
⚡ 攻擊方式
  • 坦克重裝衝撞：直線超強衝刺，轟鳴震動。
  • 掉落物品 + 扣 50% 總血量：一擊將玩家身上所有物資強制擊飛散落一地，並造成巨量傷害。
🛡️ 避戰方式
  • 地形卡位風箏法：將其引導至地形複雜、狹窄多柱子或難以直線前進的死角。
  • 趁其撞牆或轉身延遲時，立刻變向脫身逃跑。
🎯 反擊方式
  • 絕對不要反擊！：血量極其厚實，擊殺需要整整 6 發霰彈槍子彈！
  • 零回報黑洞：擊殺它沒有任何戰利品，攻擊它純屬浪費寶貴的求生彈藥。
實測備註： 千萬不要跟它硬拼！利用掩體繞開它，把有限的子彈留給真正致命的哨兵。

09. Sentryper (哨兵 / 雙鐮怪)

SENTRYPER // WEEPING ANGEL ASSASSIN
危險度 ★★★★★
⚡ 攻擊方式
  • 雙鐮狂暴斬擊：如鬼魅般瞬身欺身。
  • 一刀必死：被其近身鐮刀砍中即刻死亡，毫無生還可能。
  • 狂暴反撲：受未致死攻擊會瞬間無視一切限制直接狂衝切碎攻擊者。

  • 泣天使凝視機制：眼神鎖死！
  • 「用你炙熱的眼神注視著他！」：雙眼全程正面直視，它會被完全牽制無法瞬移。

  • 嚴禁近戰：打一下打不死它立刻反手一刀秒殺你！
  • 遠程高爆發：使用 霰彈槍遠距離射擊，2 發直接擊斃。

實測備註： 全遊戲最恐怖的殺手！絕對不要背對它，只要轉身哪怕半秒就是死刑。

10. Ramblam (雙槍羊)

RAMBLAM // DUMB GUNSLINGER
危險度 ★★☆☆☆
⚡ 攻擊方式
  • 衝刺後定點雙槍射擊：直線衝刺後停下，長前搖瞄準後射擊造成遠程傷害。

🛡️ 避戰方式
  • 調虎離山卡位法：若在撤離門口被它堵截，先往反方向開闊處跑，引誘其衝過來站穩瞄準。

🎯 反擊方式
  • 瞄準定格硬直是反殺天賜良機。
  • 它在瞄準與射擊時完全無法移動，此時持球棒或槍械直接正面或繞後反殺，輕鬆拿下。
實測備註： 看似拿雙槍很兇，實則笨拙單純，是給玩家製造極多逃跑與反殺機會的送分怪。

機制專題：聲學感知雙極對抗

MECHANICS // DUAL ACOUSTIC BEHAVIOR CONTRADICTION
機制深度解析

  • 優先級 1：指揮家極脆，持霰彈槍 2 發直接秒殺指揮家。

  • 核心收益：僅耗費 2 發霰彈槍子彈即可瓦解雙怪死局。
實測備註： 聲學機制的衝突是《謎魅狩獵》最精妙的博弈點，搞清楚當前房間的威脅屬性至關重要！

連攜解構：鼯鼠撲臉 + 炸彈自爆

SYNERGY ALERT // THE SILENT EXPLOSION COMBO

  • 觀察信號：一旦隊友突然閉麥且動作盲目亂轉，立刻上前一球棒敲死鼯鼠。

戰術教官警示： 不要以為傷害為 0 的小怪不可怕，鼯鼠的感官剝奪正是自爆魔收割全隊的最佳掩護！
